# Тестовое задание 101 Hotels

Тестовое задание на позицию Vue.js Frontend Разработчик.

Приложение представляет собой список комментариев с возможностью добавления и удаления, сортировки и постраничной навигации.

## Стек

* Vue 2
* Vuex
* Axios
* Laravel 8
* PHP 7.4
* SQLite
* Docker
* vue2-datepicker

## Возможности

* просмотр списка комментариев;
* добавление комментария без перезагрузки страницы;
* удаление комментария без перезагрузки страницы;
* постраничный вывод по 3 комментария;
* выбор страницы;
* сортировка по ID;
* сортировка по дате;
* сортировка по возрастанию и убыванию;
* автоматическое изменение страницы после добавления или удаления комментария;
* выбор даты через `vue2-datepicker`;
* оценка комментария от 1 до 10;
* отображение аватара по первой букве имени;
* адаптивная верстка.

## Установка

### Требования

Для запуска проекта необходимы:

* Docker Desktop;
* Docker Compose.

### Запуск

Клонировать репозиторий:

```bash
git clone https://github.com/MakkksT/frontend-test-101-hotels.git
cd frontend-test-101-hotels
```

Запустить Docker-контейнеры:

```bash
docker compose up -d
```

Инициализировать Laravel и установить зависимости:

```bash
docker compose exec app bash
```

Внутри контейнера выполнить:

```bash
bash ./init.sh
```

После завершения инициализации собрать JavaScript:

```bash
yarn dev
```

После сборки приложение доступно по адресу:

http://localhost

## API

| Описание                 |  Метод | URL                  |
| ------------------------ | :----: | -------------------- |
| Получить все комментарии |   GET  | `/api/comments`      |
| Получить комментарий     |   GET  | `/api/comments/{id}` |
| Создать комментарий      |  POST  | `/api/comments`      |
| Обновить комментарий     |  PATCH | `/api/comments/{id}` |
| Удалить комментарий      | DELETE | `/api/comments/{id}` |

## Структура Frontend

Основной код Vue-приложения находится в:

```text
resources/js/
├── app.js
├── store/
│   └── index.js
└── views/
    └── app.vue
```

`app.vue` содержит интерфейс приложения, сортировку, пагинацию и форму добавления комментария.

`store/index.js` отвечает за хранение комментариев в Vuex и взаимодействие с API через Axios.

## Дополнительные изменения

### Исправление сборки Docker

В исходном Dockerfile использовались устаревшие Debian-репозитории, из-за чего сборка контейнера могла завершаться ошибкой при выполнении `apt-get update`.

Dockerfile был адаптирован для работы с архивными репозиториями Debian и отключения устаревшего `bullseye-security`.

### Дополнительные элементы интерфейса

В приложение добавлены рейтинг комментария и аватар пользователя.

Эти элементы были добавлены на основе интерфейса оригинального сайта 101 Hotels и адаптированы для тестового задания.

* рейтинг комментария от 1 до 10;
* специальное сообщение для оценки 10/10;
* аватар формируется автоматически из первой буквы имени пользователя.

### Работа с пагинацией

Дополнительно реализована корректная работа пагинации после изменения списка комментариев:

* после добавления комментария пользователь автоматически переходит на страницу, где находится новый комментарий с учетом текущей сортировки;
* после удаления последнего комментария на странице текущая страница корректно изменяется, если она больше не существует.
